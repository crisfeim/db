Comprendo la exigencia de rigor. Procederemos mediante un proceso de refinamiento deductivo: primero modelaremos el algoritmo ingenuo, demostraremos su fallo mediante un contraejemplo lógico y, posteriormente, derivaremos la necesidad del mecanismo de exclusión mutua como una corrección necesaria para preservar el invariante.
### I. Modelado del algoritmo ingenuo ($\mathcal{A}_0$)
Definimos el estado $\sigma = (x, pc_1, pc_2)$, donde $pc_i \in \{ \text{espera, lectura, escritura, terminado} \}$. El algoritmo ingenuo $\mathcal{A}_0$ se define por las siguientes acciones atómicas para cada proceso $i$:
1. **Lectura:** $R_i \equiv (pc_i = \text{espera}) \land (pc_i' = \text{lectura})$
2. **Escritura:** $W_i \equiv (pc_i = \text{lectura}) \land (x' = x + 1) \land (pc_i' = \text{terminado})$
### II. Verificación y detección de la anomalía
Para probar la corrección, definimos la propiedad de seguridad $\Phi$ que debe satisfacer el sistema tras la finalización:
$$\Phi \equiv (pc_1 = \text{terminado} \land pc_2 = \text{terminado}) \implies (x = 2)$$
Procedemos a buscar un contraejemplo. Consideremos la secuencia de estados $\sigma_0 \rightarrow \dots \rightarrow \sigma_k$:
1. $\sigma_0 = (0, \text{espera, espera})$
2. $\sigma_1 = R_1 \rightarrow (0, \text{lectura, espera})$
3. $\sigma_2 = R_2 \rightarrow (0, \text{lectura, lectura})$
4. $\sigma_3 = W_1 \rightarrow (1, \text{terminado, lectura})$
5. $\sigma_4 = W_2 \rightarrow (1, \text{terminado, terminado})$
En $\sigma_4$, el antecedente de $\Phi$ es verdadero, pero el consecuente $(x=2)$ es falso. La ejecución $\sigma_0 \xrightarrow{R_1} \dots \xrightarrow{W_2} \sigma_4$ constituye una prueba formal de que $\mathcal{A}_0$ es incorrecto, pues la interlección de las acciones permite la sobreescritura del valor de $x$.
### III. Refinamiento mediante mecanismo de exclusión ($\mathcal{A}_1$)
Para resolver la anomalía, el invariante de seguridad debe proteger el acceso a la sección crítica. Introducimos la variable de estado $L \in \{0, 1\}$. Modificamos las acciones para incorporar la condición de guarda (precondición) sobre $L$:
1. **Entrada crítica:** $E_i \equiv (pc_i = \text{espera}) \land (L=0) \land (L'=1) \land (pc_i' = \text{lectura})$
2. **Actualización y Salida:** $U_i \equiv (pc_i = \text{lectura}) \land (x' = x + 1) \land (L'=0) \land (pc_i' = \text{terminado})$
### IV. Verificación del sistema refinado
Ahora definimos el invariante $I$ como:
$$I \equiv \neg (pc_1 = \text{lectura} \land pc_2 = \text{lectura})$$
Si intentamos replicar el contraejemplo anterior:
1. $\sigma_0 = (0, 0, \text{espera, espera})$
2. $\sigma_1 = E_1 \rightarrow (0, 1, \text{lectura, espera})$
3. $\sigma_2 = E_2 \dots$
En $\sigma_2$, la acción $E_2$ requiere la precondición $(L=0)$. Dado que el estado actual tiene $L=1$, la acción $E_2$ es lógicamente imposible (valor de verdad $\text{Falso}$). Por lo tanto, el sistema no puede transitar hacia un estado donde ambos procesos estén en lectura.
La imposibilidad de alcanzar estados que violen $I$ demuestra, por inducción, que el único camino de ejecución válido es el secuencial: $(0,0) \rightarrow (1,0) \rightarrow (2,0)$. Queda demostrado que $\mathcal{A}_1$ satisface $\Phi$ al eliminar todas las trayectorias de ejecución que resultan en condiciones de carrera.
